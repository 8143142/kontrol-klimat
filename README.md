# Контроль Климат — React/Vite проект для Node.js 20.11

Эта версия закреплена на Vite 5, чтобы запускалась на Node.js v20.11.0.

## Запуск

```bash
npm install
npm run dev
```

Если до этого уже запускали старую версию, удалите папку `node_modules` и файл `package-lock.json`, потом снова выполните `npm install`.

## Где заменить номер

Файл: `src/data.js`

Замените:
- `+7 777 000 00 00`
- `77770000000`


## Исправление белого экрана
В проект добавлен `vite.config.js`, чтобы React JSX корректно собирался через `@vitejs/plugin-react`.
